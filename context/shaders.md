# shaders/*.wgsl

WGSL shaders sharing `Transform4D` (`rotation_matrix`, `viewer_distance`, `sticker_scale`, `face_gap`, `face_gap_4d`, `elapsed_seconds`), `CameraUniform`, and `StickerInstance` structs plus 4D math functions, all defined once in `math4d.wgsl` and pulled into each pipeline shader via `naga_oil`'s `#import` (composed in `renderer.rs` through a `naga_oil::compose::Composer`, since WGSL itself has no import mechanism). `sticker_common.wgsl` similarly shares `LightUniform`, `HighlightingUniform`, the `piece_slots` storage array, and the `sticker_order` storage array (and their bound globals) across every sticker material shader and the particle pipeline; its `@group(0) @binding` numbers are ordered by descending readership across the classic/elemental/particle pipelines rather than by which module owns the declaration. `classic_shader.wgsl` is the Classic theme's sticker material (flat per-`kind` colors from a `KindColors` uniform); `elemental_shader.wgsl` is the Elemental theme's, switching on `kind` to pick an animated material per element (helpers `hash11`/`hash21`/`value_noise1`/`fresnel`/`strobe` shared via `elemental_common.wgsl`, which also holds `LIGHTNING_STROBE_HZ` and `ICE_TWINKLE_HZ` so each element's material animation and its particles stay on one beat) and driven by `Transform4D.elapsed_seconds`. `particle_shader.wgsl` draws the Elemental theme's billboarded particles: a per-`kind` count of camera-facing quads per sticker (`Theme::particles_per_kind`, renderer.rs), generated entirely in the vertex shader from `@builtin(vertex_index)`/`@builtin(instance_index)` with no vertex buffer and no stored particle state - `sticker_index` is looked up from `sticker_common::sticker_order`, an indirection buffer grouping instances into contiguous `(face_id, kind)` blocks so `renderer.rs` can issue one draw per visible face and populated kind at that kind's own budget - and each particle's launch direction and age are hashed from its instance index against the current lifetime cycle, so the whole system is a function of `elapsed_seconds`. Per-element tuning lives in its own `particle_style(kind)` switch, with all distances expressed in sticker radii. `math4d.wgsl`'s `compute_sticker_anchor` supplies the sticker's projected world center plus the three half-edge vectors of its projected cube; particle directions are drawn evenly over the unit sphere in that local frame and mapped through those edges, so travel distance and billboard size follow however the 4D projection has warped that particular sticker - unequally per axis, not by one shared scale.
