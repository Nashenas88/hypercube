# solver/

Under construction: a solver ported from Don Hatch's `NdSolve.java` (Magic Cube 4D, by Melinda Green & Don Hatch — http://superliminal.com/cube/cube.htm). See `solver/mod.rs`'s module doc for how the algorithm works; nothing beyond the coordinate/move-mapping foundation has landed yet (`#![allow(dead_code)]` on the module reflects that - it isn't wired into the app).

- `coords.rs` — NdSolve's doubled coordinate system (`Coords = [i8;4]`, cubie centers at `{-2,0,2}`, stickers additionally at `±4` on the axis they face), kept separate from `piece.rs`'s undoubled `[i8;4]` positions because it can name a single sticker, not just a piece. `rot90`/`rot90s` rotate a point 90° about a plane; `Twist { face_axis, face_sign, from_axis, to_axis }` is one outer-side quarter-turn in this coordinate system (no `slices_mask`, unlike the Java original — every twist here turns a whole outer side, since the puzzle has no independently-turnable inner slices) and `twist90`/`twist90s` apply it/them.
- `native.rs` — bridges `Twist` to this project's native `moves::Move`. `twist_to_move` derives the single ±90° move about the local axis not involved in the twist's `from_axis`/`to_axis` pair (proven against an independent doubled-coordinate oracle for all 48 twists, from solved and scrambled states). `merge_stage` composes consecutive same-side twists (NdSolve's raw output) into this project's richer native moves (90°/180° face, 180° edge, ±120° corner) using a stack, dropping runs that cancel to identity — sound across gaps too (`A B B' A'` → nothing), since cancelling `B B'` wherever it sits doesn't change the surrounding product (associativity, not commutativity).

Not yet ported: the grid/validation layer, `solvable.rs`, and the actual position/orient algorithm (`position.rs`, `orient.rs`) — the several-hundred-line core of NdSolve that finds and executes the 3-cycles and flip/twirl pairs. Playback wiring in `shader_widget.rs`/`app.rs`/menus and the About-dialog credit also aren't done. See the plan this was built from for the full design.
